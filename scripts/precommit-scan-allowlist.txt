# scripts/precommit-scan.sh 的允許清單：確認是假值（測試與文件裡的範例）才放進來。
# 格式：每行三欄，欄位之間用 tab 或兩個以上的空白——
#   路徑的 glob   樣式名稱   值的正規式
# - 路徑從 repo 根目錄算起；glob 的 * 與 ** 都能跨資料夾。路徑不能只是 * 或 **。
# - 樣式名稱是掃描輸出裡冒號後面那一段（例如 private-ip），一行只放一個樣式。
# - 值的正規式（Perl 的語法）要「整段」符合比對到的那段文字才放行，所以只放行寫出來的那幾個值，
#   同一個檔案裡出現別的值照樣命中。不能是空的或 .*。
# - 以 # 開頭的行與空行會略過；有格式錯誤的行會讓掃描以結束代碼 2 失敗。
# 範例：  tests/**    private-ip    10\.0\.0\.\d+
# 要加的時候：先看掃描印出的檔案與行號，確定那是假的值（不是真的權杖、位址或路徑），值盡量寫窄。
# 版本號（四段的數字）和私有位址長得一樣，會被 private-ip 誤報：用值的正規式放行那個版本號。
# 這個檔案自己也會被掃，而且不套用這份清單。
